# Agentic Skills

**Open-source skills that let AI agents drive the SKU.io API — for Claude, OpenAI, and Gemini.**

An *Agentic Skill* is a curated shortcut for an AI agent. For a real business task — *build a product
catalog*, *create a sales order*, *adjust inventory* — it tells the agent exactly which SKU.io
endpoints to call, in what order, with which fields, plus the practical e-commerce context needed to
get it right. Instead of rediscovering thousands of endpoints, an agent loads the skill and acts.

Each skill is authored **once** in a model-agnostic format and compiled to each platform's native shape:

- **Claude** — an [Agent Skill](https://docs.claude.com/en/docs/agents-and-tools/agent-skills) (`SKILL.md`)
- **OpenAI** — GPT/Assistant instructions + an importable Action (OpenAPI) + function-calling tools
- **Gemini** — system instructions + function declarations

:::tip Get the skills
The library lives on GitHub: **[github.com/skuio/sku-skills](https://github.com/skuio/sku-skills)** — MIT-licensed and open to contributions.
:::

## What's in the library

- **Build a product catalog** — import products from any source (spreadsheet, Google Sheet, supplier order form, or a website) into SKU.io
- **Find a product** — resolve a product by SKU, barcode, or search
- **Create a sales order** — place an order with line items
- **Adjust inventory** — increase, decrease, or set on-hand stock
- **Create a saved view** — build and favorite a data-table view
- **Connect to SKU.io** — authenticate with a Personal Access Token

## Use a skill

Install a built skill into your agent. For Claude, drop the folder into a `.claude/skills/` directory:

```bash
git clone https://github.com/skuio/sku-skills
cp -r sku-skills/dist/claude/products/build-product-catalog <project>/.claude/skills/build-product-catalog
```

For OpenAI, paste the generated `instructions.md` into a Custom GPT and import its `action.openapi.json`
as an Action; for Gemini, use the `system_instructions.md` and register the `function_declarations.json`.
In every case, authenticate with a SKU.io **Personal Access Token** (**Settings → Developer → Personal
Access Tokens**).
