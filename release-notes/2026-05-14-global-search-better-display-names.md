The global search palette now displays cleaner, more recognisable names
for ~50 routes across SKU.io.

<!-- truncate -->

**✨ What this means for you:**

- **Abbreviations** keep their canonical capitalisation: FBA, FNSKU,
  FIFO, RMA, COGS, GINR, AWD, PDF, OCR, AI, OAuth.
- **Brand names** render correctly: eBay, BigCommerce, WooCommerce,
  QuickBooks, Magento 2.
- 23 pages whose URL slug doesn't match the actual page name now have
  explicit titles — e.g. `/reports/real-inventory` shows up as
  *"Reports → Real-time Inventory"*, and
  `/inventory/inventory-forecasting` shows up as *"Purchase Order
  Suggestions"*. Vendor-deposits reports and FBA inventory/valuation
  subtabs are also covered.
