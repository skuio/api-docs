Demand Planning now remembers the forecast configuration you actually use, and lets you preview the effect of rerunning before you commit.

<!-- truncate -->

**✨ What this means for you:**

- Mark any saved forecast configuration as **your default** — it loads automatically each time you open Demand Planning, so you're not re-picking settings every visit.
- The configuration menu makes it clear which configuration is the default and lets you switch it.
- When you rerun a forecast schedule, a **preview** shows what the rerun will produce before it replaces the existing results — no more reruns that surprise you.

Set a default from the **Load Configuration** menu on the Demand Planning page.
