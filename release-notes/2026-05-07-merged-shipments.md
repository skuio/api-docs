Combine two or more sales orders headed to the same address into a single shipment with one tracking number — while every underlying order stays intact.

<!-- truncate -->

Select the orders to combine and SKU runs an eligibility check, then creates a **Merged Shipment** you pick, pack, and label as one unit. Each original order — and its source-channel order — keeps its own identity, and tracking writes back to all of them. SKU also suggests merge candidates on the order page, and a merge can be reversed any time before the label is purchased.
