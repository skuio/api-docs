## Added

- `DELETE /api/xero/webhook-settings/{integrationInstanceId}/events` — Bulk Delete Webhook Events
- `DELETE /api/xero/webhook-settings/{integrationInstanceId}/events/all` — Delete All Webhook Events
- `GET /api/xero/v2/accounts/export` — Export Accounts (V2)
- `GET /api/xero/v2/accounts/{account}/activity-log` — Get Account Activity Log (V2)
- `GET /api/xero/v2/bills/{bill}` — Get Bill (V2)
- `GET /api/xero/v2/bills/{bill}/activity-log` — Get Bill Activity Log (V2)
- `GET /api/xero/v2/contacts/{contact}` — Get Contact (V2)
- `GET /api/xero/v2/contacts/{contact}/activity-log` — Get Contact Activity Log (V2)
- `GET /api/xero/v2/credit-notes/{creditNote}` — Get Credit Note (V2)
- `GET /api/xero/v2/credit-notes/{creditNote}/activity-log` — Get Credit Note Activity Log (V2)
- `GET /api/xero/v2/invoices/{invoice}` — Get Invoice (V2)
- `GET /api/xero/v2/invoices/{invoice}/activity-log` — Get Invoice Activity Log (V2)
- `GET /api/xero/v2/manual-journals/{manualJournal}` — Get Manual Journal (V2)
- `GET /api/xero/v2/manual-journals/{manualJournal}/activity-log` — Get Manual Journal Activity Log (V2)
- `GET /api/xero/v2/payments/{payment}` — Get Payment (V2)
- `GET /api/xero/v2/payments/{payment}/activity-log` — Get Payment Activity Log (V2)
- `GET /api/xero/v2/purchase-orders/{purchaseOrder}` — Get Purchase Order (V2)
- `GET /api/xero/v2/purchase-orders/{purchaseOrder}/activity-log` — Get Purchase Order Activity Log (V2)
- `GET /api/xero/v2/tax-rates/{taxRate}` — Get Tax Rate (V2)
- `GET /api/xero/v2/tax-rates/{taxRate}/activity-log` — Get Tax Rate Activity Log (V2)
- `GET /api/xero/webhook-settings/{integrationInstanceId}/events` — List Webhook Events
- `GET /api/xero/webhook-settings/{integrationInstanceId}/events/summary` — Get Webhook Events Summary
- `POST /api/xero/webhook-settings/{integrationInstanceId}/events/reprocess` — Reprocess Webhook Events
- `POST /api/xero/webhook-settings/{integrationInstanceId}/events/retry-failed` — Retry Failed Webhook Events
- `POST /api/xero/webhook-settings/{integrationInstanceId}/events/{event}/reprocess` — Reprocess Webhook Event
