## Added

- `DELETE /api/customers/{customer}/payment-methods/{paymentMethod}` — Remove Card On File
- `GET /api/customers/{customer}/house-account` — Get House Account Balance
- `GET /api/customers/{customer}/house-account/history` — Get House Account History
- `GET /api/customers/{customer}/loyalty` — Get Loyalty Balance
- `GET /api/customers/{customer}/loyalty/history` — Get Loyalty History
- `GET /api/customers/{customer}/payment-methods` — List Cards On File
- `GET /api/gift-cards` — List Gift Cards
- `GET /api/gift-cards/lookup` — Lookup Gift Card by Code
- `GET /api/gift-cards/{giftCard}` — Get Gift Card
- `GET /api/gift-cards/{giftCard}/history` — Get Gift Card History
- `GET /api/loyalty/settings` — Get Loyalty Settings
- `POST /api/customers/{customer}/house-account/adjust` — Adjust House Account
- `POST /api/customers/{customer}/house-account/charge` — Charge House Account
- `POST /api/customers/{customer}/house-account/pay` — Record House Account Payment
- `POST /api/customers/{customer}/loyalty/adjust` — Adjust Loyalty Points
- `POST /api/customers/{customer}/payment-methods` — Save Card On File
- `POST /api/gift-cards` — Issue Gift Card
- `POST /api/gift-cards/{giftCard}/reload` — Reload Gift Card
- `POST /api/gift-cards/{giftCard}/void` — Void Gift Card
- `PUT /api/customers/{customer}/payment-methods/{paymentMethod}/default` — Set Default Card
- `PUT /api/loyalty/settings` — Update Loyalty Settings
